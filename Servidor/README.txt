#  Proyecto Trasversal – Pastelería

Este proyecto simula el desarrollo completo de una aplicación de gestión para una pastelería, 
separando el sistema en **cliente** y **servidor**, siguiendo una arquitectura cliente-servidor.

---

##  Descripción del proyecto

El objetivo del proyecto es desarrollar una aplicación completa que permita gestionar una pastelería digitalmente, 
incluyendo funcionalidades como:

- Gestión de productos
- Gestión de pedidos
- Interfaz para clientes
- Lógica de negocio en servidor
- Comunicación cliente-servidor

Proyecto creado con fines educativos para aplicar conocimientos de:

- Programación
- Desarrollo web
- Trabajo en equipo
- Organización de proyecto real

---

##  Estructura del proyecto

Trasversal/
